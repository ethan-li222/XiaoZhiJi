# 私有部署与恢复

本项目面向个人或少量可信用户，所有使用者共享项目、材料、批注、知识、任务和产物。访问令牌控制进入整个工作空间，不提供用户级数据隔离。受邀用户具有同等操作权限，包括删除、导入本机路径和触发模型调用。不要用于互不信任用户的开放注册服务。

## 部署

支持 Windows、Python 3.12、Node、Chrome 的源码部署。安装步骤见 [README](../README.md)。`requirements.lock.txt` 与 `ppt/package-lock.json` 用于固定依赖。首次下载嵌入模型后可离线索引材料；论文来源、网页导入及云模型仍需联网。

```powershell
conda activate agent
cd C:\path\to\research-agent
python -m research_agent.cli doctor --mcp
python -m research_agent.cli access-init
python -m research_agent.cli serve --port 8765
```

`access-init` 将随机令牌写入 `.env` 与 `data/secrets/private-access.txt`，终端只输出文件路径。浏览器打开 `/login`，从本机该文件复制令牌登录。令牌相当于整个共享空间的密码，只向可信受邀用户提供；不要提交、截图或写入日志。默认登录有效期 8 小时，退出会撤销当前会话。修改 `.env` 令牌并重启后，旧会话失效。

默认只监听 `127.0.0.1`。邀请远程用户时，优先通过私有网络或 VPN 访问；配置 HTTPS 反向代理并设置 `RESEARCH_SECURE_COOKIES=true`。代理应保留外部 Host/协议、处理 TLS 并配置上传与超时限制，应用端写请求校验浏览器 Origin。先验证代理后的登录、上传和退出，再发邀请。禁止直接向公网暴露未配置令牌的应用；CLI 对非回环地址启动要求至少 32 字符令牌。不要绕过 CLI 使用任意 uvicorn 监听参数。

入口存活检查 `/health` 不需要登录，只说明 HTTP 服务运行，不保证模型或上游论文接口可用。`doctor --mcp --model` 检查依赖、工具和模型，模型检查会向已配置服务发起一次请求。日志位于 `data/logs`，应由部署者限制操作系统访问权限。

## 操作与限额

- PDF/TXT/Markdown 上传默认最大 50 MB；文本要求 UTF-8。上传完成后需确认导入，上传本身不创建知识卡片。正文请求最大 2 MB。
- 同一应用进程最多执行 3 个任务，超额返回 429。部署保持单个应用 worker；不要多进程运行同一数据目录。恢复任务也遵守该限制。
- 模型综合与习惯建议需要显式点击。每次综合最多取最近 40 条笔记、30000 字，来源缺失或不足会提示。模型生成的候选 Idea 须人工采纳与核验。
- 自报阅读时间、标记已读、实际实验结果分别统计。至少 14 天窗口中有 7 天阅读记录才提供习惯建议；没有真实对照数据，不生成能力排名。
- 官方域名标记只识别来源域名，会场筛选依赖候选元数据，不能保证覆盖整个会议论文集。引用 API 限流时，本地归档和笔记仍可使用。
- 原文、批注、会话和任务可能保存敏感研究内容。发送给云模型的是当前操作所需的选段、笔记或统计；请为私有部署配置合适的模型服务。

## 备份与恢复

备份包含主数据库、LangGraph 检查点、分类 PDF、上传材料、论文下载和任务产物；不包含 `.env`、访问会话、密钥、模型权重、浏览器缓存、日志或测试目录。主数据库中已保存的正文与笔记随备份保存。来自任意外部路径的原文件不自动收集，重要文件请通过上传或分类归档保存。

必须先停止工作台并确认没有任务在执行。不要把备份存到 data 里面。示例：

使用启动器时可双击 `stop.bat` 停服，或运行 `powershell -File .\stop.ps1`；脚本核对 PID 与服务命令，只停止本启动器管理的进程。自行在终端启动的服务请在对应终端 Ctrl+C。

```powershell
python -m research_agent.cli backup create C:\backups\research-backup.zip --offline
```

备份返回 SHA-256，内部文件也逐项校验。备份含完整私有研究资料，部署者需存储到受控位置，定期复制到独立介质；本版本未内置备份加密。

恢复前停止服务，将原 `data` **重命名保留**，不要删除；确保原路径为空，再执行：

```powershell
python -m research_agent.cli backup restore C:\backups\research-backup.zip --offline
python -m research_agent.cli doctor --mcp
```

恢复只支持原绝对数据路径，以保留 PDF 与产物引用。清单、路径、文件哈希、SQLite 完整性全部通过后才放入目标目录；目标已有数据时拒绝覆盖。`.env` 需单独安全保留；模型权重可从保留目录复制或重新初始化。恢复不恢复登录会话，所有用户需重新登录。建议每周备份、每次升级前备份，并定期用临时工作空间执行恢复演练。

## 本版本上线边界

可作为可信小团队的私有试用版本。公开 SaaS 的独立账号、权限与租户隔离、配额计费、后台任务队列、多实例一致性、集中监控告警、备份加密和自动迁移尚未实现。检索质量、引用覆盖和模型建议仍受外部数据与模型能力影响，不宣称达到 Connected Papers 全量数据覆盖。公开提供服务前应单独完成这些能力及安全评审。
