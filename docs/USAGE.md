# 使用指南

安装与启动见 [README](../README.md)，访问控制和备份见 [部署指南](DEPLOYMENT.md)。

## 创建项目与添加资料

在研究工作空间创建项目，填写研究问题和关键词。通过论文搜索将结果加入材料库，下载并导入阅读；也可导入网页、上传 PDF/TXT/Markdown 或粘贴文本。

下载依赖公开 PDF 地址；网页提取取决于站点与网络。检索候选中的会场筛选不代表覆盖该会议全部论文。

## 阅读与提问

打开归档论文后，原始 PDF 与提问侧栏同屏显示。选择文字可带上选段和页码提问，也可以保存批注、解释术语或请求翻译。回答的来源可展开核对并返回原文。

- 阅读会话绑定一份文档，切换文档需使用对应会话。
- 高亮、笔记与阅读页码可保存并恢复。
- 扫描 PDF 暂无 OCR；复杂公式、表格和多栏文字可能提取不完整。
- 无法定位选段时会提示并使用检索上下文；没有相关原文时不能可靠作答。

问答历史自动保留。希望长期复用的内容，点击「保存这次问答到知识库」；历史中的单轮问答也可保存。

## 与小知己对话

对话工作区分为资料来源、对话和来源预览。点击资料标题查看提取正文，点击回答下方编号引用查看当轮来源快照，必要时进入阅读器。

### 选择本轮来源

| 操作 | 行为 |
| --- | --- |
| 指定项目，未显式选择文档 | 自动检索项目关联的已导入资料 |
| 勾选文档 | 仅检索所选文档，最多六份，可包含项目外文档 |
| 取消全部 | 不检索文档，不自动回退到项目全部资料 |
| 使用项目资料 | 清除显式文档选择，恢复项目自动检索 |
| 添加来源 | 上传/拖拽文件、导入网页或粘贴文本，索引后自动选中 |

上传资料保存在文档库，不自动建立项目归属；若需要项目归档，请在材料管理流程中添加。来源选择草稿保存在当前浏览器，成功问答的范围随会话保存在本机数据库，草稿不会跨设备同步。

### 知识与个人记忆

默认普通对话不检索笔记，但仍会使用明确选中的文档或项目说明。

- 「检索已确认的知识笔记」：召回已确认阅读知识，以及情境层的知识/经验类个人笔记。
- 「也检索已确认的个人记忆」：允许其他已确认个人记忆参与召回。
- 项目与文档选择会进一步限制笔记范围。

改变范围只影响本轮检索，不清除此前对话。希望重新开始背景时，新建对话。

### 保存与恢复

Enter 发送，Shift+Enter 换行；会话可切换、刷新恢复和导出 Markdown。失败回答可重试，同一会话回答期间不能重复提交。删除会话不删除已经保存的笔记、历史任务和导出文件。

「保存为笔记」会把所选回答存入待整理笔记，不会自动确认或写入核心记忆。当前对话显示任务阶段，回复完整返回；不会在聊天中自主联网搜索、修改记录或执行实验。

引用编号是来源导航，不是逐句证据核验。模型可能误解资料，请检查原文；发送给云模型的是本轮资料片段与受限历史，不是默认通读全部文档。

## 整理知识与记忆

「知识与记忆」包含个人笔记与阅读问答卡片。个人笔记可以独立记录学习、工作和生活知识，无需先关联论文。

| 状态 | 建议用途 |
| --- | --- |
| 待整理（inbox） | 刚保存的解释、摘记或复盘候选 |
| 已确认（confirmed） | 核对来源、补充个人理解后允许后续复用 |
| 已归档（archived） | 保留记录，退出常规召回与复盘 |

按笔记本、标签、状态与来源整理，可导出 Markdown/JSON。已确认表示本人核对，不代表系统独立验证了事实。

个人记忆分为情境、行为、认知、核心与意图。复盘只提出有来源的待复核主题；候选需人工整理，核心价值观由本人手动填写，不自动推断人格。

删除原文会删除其分块、阅读会话与阅读知识卡片；独立个人笔记保留并提示来源失效。任务结果、聊天来源快照和导出文件可能仍保存历史内容，删除原文不等于彻底擦除所有副本。

## 扩展论文关系

论文引用箭头由引用者指向被引用者。关系图可继续探索参考文献和引用者，来源分页或限流时按提示查看覆盖范围。

文献相似图根据共享参考文献（耦合）和共享引用者（共引）构建，与标题摘要的语义相似推荐分开呈现。节点/连线可查看证据；图来自有限采样，不代表完整论文关系。公式见 [架构说明](ARCHITECTURE.md#文献关系)。

## 从笔记到实验与汇报

积累项目笔记后生成研究综合，核对来源和新颖性，再采纳 Idea 候选。实验模块记录基线、数据集、指标、控制变量和结果；实验需要自行执行。

选择时间窗口生成工作汇报，在汇报制作中检查结构化大纲，再构建可编辑 PPTX。数字图表需要显式确认数据，不能把模型估计当作统计结果。PPT 预览需要 PowerPoint 或 LibreOffice。

阅读时间来自自报记录，不从页面停留推断。习惯建议依据已记录事实，并在数据不足时提示，不提供外部人群排名或能力分数。

## 常见问题

- **向量模型未初始化**：运行 `research-agent embeddings init`，需要为已有资料补向量时执行 `research-agent embeddings reindex`。没有向量时仍可全文检索。
- **论文来源 429**：等待或缩小查询；启用浏览器后可补充论文搜索，但不能保证引用图数据完整。
- **模型调用失败**：检查模型配置与网络，在任务记录中查看错误并恢复；不要连续重复提交同一会话。
- **云模型数据范围**：本地保存不等于完全离线。使用云服务会发送选定片段与受限历史，请按资料要求选择服务。
